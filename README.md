# Atelier452 Magic

界面：中文 / English（右上角一键切换）。三大工作区：
1. **中割生成** — 上传关键帧（原画），生成补间动画。两种方式：
   - **一体生成（推荐）**：全部关键帧（≤9 张）作为有序参考图，一次生成一段连续、
     上下文连贯的完整动画（内置"按顺序作为关键帧、一镜到底"提示词），时长 4–15 秒
   - **分段生成**：相邻两帧首尾帧补间，逐段生成后拼接（每段独立，上下文不连续）
2. **成片上色** — 把粗动画（线稿）按参考图转绘/上色为最终成片（视频转视频）
3. **原画精修** — 草稿/tie-down 线稿 → 干净的完成版原画（Seedream 图生图，
   需在方舟控制台开通 seedream 模型；模型 ID 在 API 设置里改）

通用：**提示词库**（每个提示词框旁的 📚，预设一键填入/保存/删除，存于 config.json）；
所有提示词框聚焦自动展开；图片悬停放大。

## 启动

**桌面版（推荐）**：双击 `dist\Atelier452Magic.exe`（portable 单文件）。
数据（配置/工程/生成结果）存放在 exe 旁边的 `Atelier452Data\` 文件夹——移动 exe 时把这个文件夹一起带走。
重新打包：`npm run dist`（产物在 `dist\`）；开发调试窗口：`npm run app`。

**网页版（开发）**：

```
cd inbetween-studio
npm install
npm start        # http://localhost:5893
```

两者用同一个端口 5893，不要同时开（后启动的会自动复用已有实例的服务器）。

依赖：
- Node.js ≥ 18
- ffmpeg（自动从 PATH / winget 安装目录查找，可设 `FFMPEG_DIR`）
- cloudflared（可选，成片上色需要：`winget install Cloudflare.cloudflared`）

## 生成后端（火山方舟 Seedance）

右上「⚙ API 设置」填 ARK API Key（`ark-` 开头）。需在方舟控制台开通对应模型：
- **中割模型**：任意支持首尾帧的模型（`role: first_frame/last_frame`）
- **转绘模型**：需支持视频输入的模型（Seedance 2.0 系，`role: reference_video`）

不填 Key 时用 ffmpeg 本地模拟（中割=交叉溶解，上色=调色滤镜），方便跑通流程。

**转绘的源视频必须公网可访问**：应用自动用 cloudflared 起免费隧道，只暴露 5894 端口的
只读文件服务（`/videos`、`/assets`，文件名随机），不暴露 API 与配置。也可在设置里填
自己的公网基址（如对象存储/自有域名）。注意：隧道刚建立的第一次请求偶尔会因 DNS
未生效失败，重试即可。

## 功能

### 中割生成
- 关键帧多选上传 / 拖拽排序 / 删除；重排后相同图片对的结果自动复用
- **一体生成**：全部关键帧一次成片，带生成历史（回看/下载/一键送去转绘上色）
- **演技强度滑杆**（1–100，五档）：自动生成对应强度的内置演技提示词（克制→sakuga）
- 每段时长（最短 4 秒）、动作提示词、**风格锁定提示词**（自动附加，防止画风漂移）
- 连续预览（canvas 逐帧）、时间重映射（目标总时长 + fps）、自动缓急（运动量加权抽帧）
- 分段卡片：v1/v2… 版本切换、重生成、单段详细设置
- 导出：拼接 mp4 / PNG 序列 zip / 按重映射导出

### 成片上色（V2V）
- 源视频：上传，或一键引用中割拼接结果
- 参考图多张（`reference_image`）+ **内置上色提示词**（可改，自动作为主指令）
- 生成时长 4–15s（自动带入源视频时长）
- **生成历史**：每次结果存档，点任意版本回看/下载

### 工程持久化
所有状态（关键帧、分段版本、V2V 历史、参数）自动保存到 `data/project.json`，
刷新页面 / 重启服务器后自动恢复。素材存 `data/assets/`，生成结果存 `videos/`。

## 结构

```
server.js        Express：Seedance 任务、隧道、上传、持久化、ffmpeg 模拟/拼接/转码
public/app.js    前端全部逻辑（无框架）
public/index.html / style.css
data/            工程状态 + 上传素材（gitignore）
videos/          生成与导出结果（gitignore）
config.json      API Key 与模型配置（gitignore，勿提交）
```
